Lastdrop — flyout, final design

The flyout speaks the taskbar’s language at a larger size: the same pace bar (1 px track, 3 px fill, 1 px tick at the share of the window gone), the same reset glyph, the same words when something is wrong, and colour only for trouble. It is a Windows 11 tray flyout: acrylic backdrop (solid when transparency is off), 8 px corners, Segoe UI Variable and Segoe Fluent Icons, WinUI 3 colour tokens, following the Windows mode (the taskbar’s light/dark) like Quick Settings beside it. One card per service: name, plan, data age and a 14-day sparkline on one line, then its meters. Balance services (Meshy) show the amount and how long it lasts instead of a bar.

Trouble rule, as in the taskbar
Colour appears only with a severity glyph and words: caution fill + triangle + “Out 15:20”; critical fill + disc + a countdown (“12 min left”, “6 h left”: critical never shows a clock time); “Back 16:30” when empty. Text stays in the text colours (InfoBar convention), so it keeps its contrast.

Calm rule
On track, bars use the accent (WinUI ProgressBar), which reads as neutral in an app surface; the taskbar uses its monochrome text colour. Both carry the same 1 px tick at the share of the window gone.

Sparkline
Top right of every card: use per day, last 14 days (today in accent, on the right). For windows it is the share of the longest window used that day; for balances, credits spent. Each scales to its own 14-day maximum, with a floor so a quiet fortnight stays low.
